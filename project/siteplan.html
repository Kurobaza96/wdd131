1. Site Name

Sabores de Guatemala

Sabores de Guatemala means "Flavors of Guatemala." The name represents a website dedicated to introducing traditional Guatemalan foods and the culture and traditions connected to them. I chose this name because food is an important part of Guatemala's identity, history, and cultural heritage.

The website will introduce visitors to traditional dishes such as Tamales, Kak-ik, Tostadas, and other foods from Guatemala.

2. Site Purpose

The purpose of Sabores de Guatemala is to provide information about traditional Guatemalan foods and the cultural traditions associated with them.

The website will introduce visitors to popular traditional dishes such as Tamales, Kak-ik, and Tostadas. Each food will include an image, description, main ingredients, and cultural information.

The website will also explain the influence of Maya culture on Guatemalan cuisine and highlight traditional ingredients and cooking techniques, including the use of toasted ingredients in sauces and other preparations.

Target Audience

  • People from other countries interested in Guatemalan culture.
  • Tourists interested in traditional Guatemalan food.
  • People learning about Guatemala and its history.
  • Guatemalans interested in traditional cuisine.
  • Anyone interested in Central American food and culture.

3. Scenarios

The following questions represent information that visitors might want to find when visiting the website:

  1. What are some traditional foods from Guatemala that I should try?
  2. What are the main ingredients used in traditional Guatemalan dishes?
  3. What is the cultural significance of Kak-ik?
  4. How has Maya culture influenced traditional Guatemalan food?
  5. Which Guatemalan foods are considered traditional antojitos?

Planned Project Features

The final website will contain at least three pages with consistent navigation and visual design.

  • Home: Introduction to Guatemalan traditional foods and featured dishes.
  • Traditional Foods: Interactive collection of foods that can be filtered by category.
  • About: Information about Guatemalan food, Maya influence, ingredients, and traditions.
  • References: Sources used for information and images.

JavaScript Features

  • Dynamic generation of food cards.
  • Food category filtering.
  • Arrays and objects containing food information.
  • Array methods such as filter(), map(), and forEach().
  • DOM element selection and modification.
  • Event listeners for interactive controls.
  • Conditional branching.
  • HTML form interaction.
  • Form data stored using localStorage.
  • Template literals for dynamically generated output.

Images

Images will be optimized for web performance and appropriate alternative text will be provided. Images that are not part of the initial viewport will use lazy loading.

Testing

The completed website will be tested using the common tools used throughout the WDD131 course.

  • HTML validation.
  • CSS validation.
  • Accessibility testing.
  • Color contrast testing.
  • Lighthouse performance testing.
  • Lighthouse best practices testing.
  • SEO testing.
  • Responsive design testing.
  • Mobile portrait and landscape testing.
  • Desktop testing.
  • Spelling and grammar review.

The website will use semantic HTML, descriptive alternative text for images, appropriate heading hierarchy, readable typography, sufficient color contrast, and responsive layouts.
